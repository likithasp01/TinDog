🐶 TinDog - Tinder for Dogs
TinDog is a fun, responsive front-end web project that mimics a dating app — but for dogs! Built using HTML, CSS, and Bootstrap, this project showcases modern design practices and component-based layouts while helping me practice web development concepts.

Tech Stack:
HTML5
CSS3
Bootstrap 5.3

Features:
Responsive layout with Bootstrap 5
Catchy hero section with call-to-action buttons
Feature cards with SVG icons
Testimonial section with image and logos
Pricing cards with clear plans
Clean, structured, and reusable Bootstrap components

What I Learned:
Responsive grid system with Bootstrap
Button groups and card layouts
Using container and row/column logic effectively
Embedding SVGs for crisp, scalable icons
Section-based semantic HTML design
