## 🐶 TinDog - Tinder for Dogs
TinDog is a fun, responsive front-end web project. Built using HTML, CSS, and Bootstrap, this project showcases modern design practices and component-based layouts while helping me practice web development concepts.

## Tech Stack:
- HTML5
- CSS3


## Features:
Responsive layout with Bootstrap 5
Feature cards with SVG icons
Testimonial section with image and logos
Pricing cards with clear plans
